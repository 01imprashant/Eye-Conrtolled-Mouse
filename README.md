# Eye Controlled Mouse

This project implements an eye-controlled mouse using a webcam, Mediapipe, and OpenCV. The application tracks facial landmarks to move the mouse cursor and detects blinks to simulate mouse clicks.

## Features

- **Cursor Movement**: Tracks specific facial landmarks to move the mouse cursor.
- **Blink Detection**: Detects eye blinks to perform mouse clicks.
- **Real-Time Processing**: Uses a webcam feed for real-time interaction.

## Requirements

The project requires the following Python packages, which are listed in the `requirements.txt` file:

- OpenCV (`opencv-contrib-python`)
- Mediapipe
- PyAutoGUI
- NumPy
- Other dependencies listed in `requirements.txt`
